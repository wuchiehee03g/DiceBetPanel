# 吹牛王投注站 · 網頁版

## 目標
把 `骰俠吹牛王-投注站.html.html` 原型變成可公開分享、多人同時下注即時同步的網頁，
部署到 GitHub Pages，之後用 Claude Code 改完直接 push 上線。

## 已確認的決策
- 權限：**維持全開放**，不做登入或 PIN（朋友間信任制）
- 盤口：只保留「總冠軍」+ 自訂特別投注盤，不預建各階段賽程盤
- 單邊池：沒有對手池時 **1.00x 全額退還、不抽水**
- 身分：裝置記憶暱稱 + 「我的下注」分頁
- 抽水：5–10% 滑桿（沿用），結算時快照該盤實際抽水率
